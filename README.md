# EcoWatt

EcoWatt is an interactive energy dashboard that demonstrates how conventional and renewable energy choices can affect estimated household energy consumption, cost, and CO₂ emissions.

## Demo & Preview

- **Live demo:** https://mhazeemshafi.github.io/Ec0Watt/
- **Repository:** https://github.com/MHazeemShafi/Ec0Watt

## Features

- Switch between conventional and renewable-energy household scenarios
- Interactive dashboard showing estimated consumption, costs, and emissions
- Visual comparison bars and a 24-hour energy chart
- Illustrative daily and yearly savings information
- Responsive layout for desktop and mobile screens
- Reduced-motion support for users who prefer fewer animations

> **Important:** The dashboard uses sample demonstration values. It is not connected to a real smart meter or live energy service, and its figures should not be treated as precise household estimates.

## Built With

- HTML5
- CSS3
- JavaScript
- SVG for scalable visual elements

The project uses vanilla web technologies and does not require a frontend framework.

## Requirements

- A modern web browser
- Git (optional, for cloning)
- No package manager, API key, or external backend is required for the current demo

## Installation

```bash
git clone https://github.com/MHazeemShafi/Ec0Watt.git
cd Ec0Watt
```

## Quick Start

Open `index.html` in your browser. For local development, open the folder in VS Code and use Live Server.

## Configuration

No environment variables or API keys are required. The current dashboard uses sample data; update the relevant JavaScript values if you want to experiment with different demonstration scenarios.
